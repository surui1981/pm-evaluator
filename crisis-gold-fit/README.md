# 经济危机金价拟合曲线 —— 核心逻辑与部署说明

> 一套从 PM-Evaluator（贵金属投资窗口预期评估器）中剥离出来的**金价危机周期拟合算法**。  
> 零依赖、纯计算，可在任意应用（Node / 浏览器 / Python / 其他语言照公式移植）中部署。



---

## 一、它在做什么（一句话）

把 **2000 互联网泡沫**、**2008 次贷危机** 两轮真实金价走势，按「距金价阶段高点的月数」对齐并归一化成"高点=100"的模板，取两轮**等权平均**作为"经济周期典型路径"，再用当前金价锚定这条模板，最后叠加一个**康波长波漂移**向外外推 30 个月，得到一条参考性的"未来金价路径"。

它**不是回归、不是预测**，而是"历史形态参照 + 情景假设"：给出"如果这次危机重演历史平均路径，金价大致会怎么走"的可视化参考。

---

## 二、核心算法（四步，附数学公式）

### 符号约定

- `peak` = 某轮周期的金价阶段高点所在月（如 2000-02、2008-03）
- `t` = 距 peak 的月数，`t = monthIdx(月) − monthIdx(peak)`，其中 `monthIdx("YYYY-MM") = 年×12 + (月−1)`
- `P(月)` = 该月金价（月均价，美元/盎司）
- `N(t) = P(peak+t) / P(peak) × 100` —— 归一化指数（高点月 = 100）

### 第 1 步：归一化对齐

对每一轮历史周期，把它的月均价序列转成 `(t, N(t))` 序列（只取 `t ≥ 0`）：

```
N_i(t) = P_i(peak_i + t) / P_i(peak_i) × 100
```

### 第 2 步：等权模板 + 线性插值

对每个 t，把所有周期在该月的 `N_i(t)` 取算术平均（等权），得到模板 `T(t)`：

```
T(t) = (1/n) · Σ_i N_i(t)      （n = 周期数，这里 = 2）
```

模板是离散点，用**线性插值**补齐任意 t；超出两端时取端点值（clamp / 平台外推）。

### 第 3 步：锚定当前周期

- 当前周期月均价 `Mcur` 由**日线按自然月聚合**而来（末月可能未收盘）。
- 锚点月 `anchorMonth` = 当前日线**最高价所在月**；其月均价 `A = Mcur(anchorMonth)`。
- 当前处于模板的哪个位置：`t0 = monthIdx(最新月) − monthIdx(anchorMonth)`
- 当前归一化值：`curNorm = Mcur(最新月) / A × 100`
- 缩放因子（让拟合线**精确穿过当前点**）：`scale = curNorm / T(t0)`

### 第 4 步：康波长波漂移外推

对 `t = t0 … t0+H`（`H=30` 个月）：

```
Fit(t)  = T(t) × scale × (1 + g)^(t − t0)
价格(t) = A × Fit(t) / 100
```

其中 `g = 0.003`（+0.3%/月 ≈ +3.7%/年），代表长波萧条期去美元化与央行购金的结构性支撑。

**单周期区间**：额外用每一轮历史周期单独外推到 `t0+H`，得到离散终点（展示用，说明均值受单轮周期影响的范围）。

### 关键参数

| 参数         | 值      | 含义                    |
| ---------- | ------ | --------------------- |
| H（horizon） | 30     | 外推月数                  |
| g（drift）   | 0.003  | 康波长波月度漂移（示意参数，非统计回归）  |
| 权重         | 等权     | 2000 / 2008 两轮周期各 50% |
| 归一化基准      | 高点=100 | 每轮以自身金价阶段高点月为 100     |

## 三、数据契约（移植时必须提供）

### 1. 历史周期 `cycles`

```json
[
  {
    "short": "2000 科技股泡沫",
    "goldPeak": "2000-02",
    "series": [["1999-01", 287], ["2000-02", 300], ...]   // [YYYY-MM, 月均价]
  },
  { "short": "2008 次贷危机", "goldPeak": "2008-03", "series": [...] }
]
```

完整数据见 `data/cycles.json`（源自世界银行 Pink Sheet 月均价 + MetalCharts 日线交叉核对）。

### 2. 当前周期日线 `dailyNodes`

```json
[ {"date": "2026-08-25", "last": 4715.9}, ... ]   // 日期 + 收盘价
```

示例见 `data/daily_example.json`。生产环境把你自己的日线序列喂进来即可。

### 输出 `fit`

```
fit.meta     锚点月/锚点价/最新月/curNorm/t0/参数
fit.curve    [{t, month, norm, price}, ...]  ← 画图用这条
fit.endpoint 30 个月终点
fit.gainPct  终点相对当前涨幅
fit.cycleEnds 各单周期终点（离散区间）
```

## 四、部署步骤

**Node / 浏览器（JS 版）**

```bash
# Node
node demo.js                       # 直接看结果
# 你的应用里：
const { buildCycleFit } = require('./gold_cycle_fit.js');
const fit = buildCycleFit({ cycles, dailyNodes, horizon: 30, drift: 0.003 });
// fit.curve → 喂给 ECharts / Chart.js / 任意折线图
```

浏览器里 `<script src="gold_cycle_fit.js"></script>`，用全局 `GoldCycleFit.buildCycleFit(...)`。

**Python 版**

```bash
python demo.py
# 你的应用里：
from gold_cycle_fit import build_cycle_fit
fit = build_cycle_fit(cycles=cycles, daily_nodes=daily, horizon=30, drift=0.003)
```

**其他语言**：照第二节四步公式移植即可，核心只有"月份差 → 归一化 → 等权均值 → 线性插值 → 锚定缩放 → 幂函数漂移"这几步，无需任何库。

**前端画图提示**：X 轴用 `curve[].month`（或 `t`），Y 轴用 `curve[].norm`（归一化图，画一条 `y=100` 的基准线）；若要显示美元价，用 `curve[].price`。原应用中拟合线是**紫色虚线** `#c792ea`，仅作参考层，不进主评分。

## 五、验证结果

移植版与原应用内联逻辑逐点比对（31 个点，`t0=3`、`curNorm=89.1`）：**归一化值、隐含金价、月份全部一致**；JS 版与 Python 版输出也完全一致。用包内示例数据跑出的结果：

- 锚点 2026-08 月均价 $4466（日线峰值 $4715.9 @ 2026-08-25）
- 最新 2026-11 月均价 $3978，归一化 89.1（较锚点 −10.9%）
- 外推 30 月终点 2029-05：归一 132.8，隐含 **$5930**（较当前 +49.1%）
- 单周期终点：2000 泡沫 → $5049；2008 次贷 → $6810（区间离散，说明均值路径的不确定）

## 六、⚠️ 免责声明（务必随功能一起呈现给用户）

1. **这是情景参考，不是预测**。均值模板受 2008 年后 QE 大牛市影响**偏乐观**。
2. `drift = +0.3%/月` 是**研究示意参数**，不是历史统计回归的结果。
3. 不同周期的宏观背景、货币购买力、投资者结构**不可比**；名义价格未做通胀调整。
4. 历史类比只描述形态路径，**不构成任何投资建议**。反转/见底须结合政策转向（降息、弱美元）、站上 MA20 等确认信号判断，不可把"磨底"直接等同于底部。
