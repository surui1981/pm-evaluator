# 贵金属投资窗口预期评估器（PM-Evaluator）

> 面向黄金 / 白银等贵金属金融衍生品的**投资窗口预期评估**交互式 Web 应用。
> 基于「主权国家 / 美元指数 / 美债收益率」三大支柱框架，对 13 项黄金定价因子按典型经验赋权，
> 输出 **0~100 分制综合分** 与 **五档窗口评级**，为入场时机提供有指向性的参考建议。

- **当前版本**：**v0.6.4**（2026-11-20）——评估指数逐日变化修复 + 旧数据回放覆盖修复；其后增量功能（自动刷新档位、绿色实际金价曲线、标线对齐、数据来源新鲜度派生）随当日发布，未再升版本号。完整演进见 [第十章](#十版本演进路线)。
- **形态**：单文件 HTML + ECharts（CDN）+ 内联 JS/CSS，零构建依赖，可静态托管；另附可选的 Node.js + SQLite 后端 API
- **数据**：每日自动刷新、按日归档，截至 2026-11-20 已积累 **125 个交易日**（2026-06-09 起），跨设备可追溯
- **线上发布**：https://53cf0c85b9a1454f866fc79f5cb50b73.app.workbuddy.host/?sharecode=R7GWSYR7BB （分享链接需带 `sharecode`）
- **当前研判**（2026-11-20）：score100 **26.9** / 偏空窗口 · 减仓避险；趋势层 **流动性挤兑·磨底 / 向下 / 宏观与价格共振 / 反转触发 0/5**

## 二、评估体系

### 2.1 三支柱框架

| 支柱 | 权重 | 覆盖维度 |
|------|------|----------|
| 支柱一 · 实际利率与美债收益率 | 38% | TIPS 实际利率、名义收益率、政策利率、曲线斜率 |
| 支柱二 · 美元指数与政策分化 | 27% | DXY、贸易加权美元、美欧政策利率分化 |
| 支柱三 · 主权央行与避险需求 | 35% | 央行购金、地缘风险、美元信用风险、VIX、GLD ETF 资金流 |

### 2.2 13 项评估参数与权重（全局权重和 = 1.00）

| 参数 | 所属支柱 | 权重 | 方向（对金价） |
|------|----------|------|----------------|
| 10Y TIPS 实际利率 | 一 | 21% | 实际利率↑ → 金价↓（负相关） |
| 10Y 名义国债收益率 | 一 | 11% | 收益率↑ → 金价↓ |
| 2Y 国债收益率 | 一 | 6% | 政策预期定价 |
| 联邦基金利率 | 一 | 6% | 利率中枢高 → 金价承压 |
| 收益率曲线斜率 2s10s | 一 | 2% | 倒挂 → 衰退避险 → 利多 |
| 美元指数 DXY | 二 | 19% | 美元越强 → 金价越弱 |
| 美元贸易加权指数 | 二 | 8% | 广义美元强弱 |
| 美欧政策利率分化 | 二 | 6% | 美溢价宽 → 美元强 → 利空 |
| 全球央行季净购金 | 三 | 5% | >300t 强多（结构性底） |
| 地缘风险指数 GPR | 三 | 4% | 避险需求 |
| 美元信用风险指数 | 三 | 3% | 财政/赤字风险 → 利多 |
| 避险情绪 VIX | 三 | 6% | 常态：恐慌→利多；权益外溢状态：恐慌→利空（状态化，见下） |
| GLD ETF 月度流量 | 三 | 3% | 净流入 → 机构支撑利多 |

> **v0.5 权重说明（2026-11-17）**：四个季频/手填的结构性慢变量（cb/gpr/fiscal/etf）合计权重由 30% 减半至 15%——它们天天不变，作为日频择时因子会把周期信号钉死在中性档（v0.4 的 122 个交易日 100% 落中性）。腾出的权重按有效性补给周期项（TIPS、10Y、DXY）。**VIX 状态化**：当 `10Y≥5% 且 DXY≥103`（或 `VIX≥30`）判定为「权益外溢」regime 时，黄金呈风险资产特征，高 VIX 改按「流动性挤兑/保证金抛售 → 利空金」计分（映射由 +0.9 翻为 −0.6）。**资金流影子层** `flowShadow`（黄金/美债比价 + 20 日金价动量）仅记录于 provenance，不进主分。

### 2.3 100 分制与五档窗口

- 内部评分口径为 **-1 ~ +1**（每个参数经经验映射函数得到利多/利空强度），对外展示统一换算为 **0~100 分制**：`分 = (内部分 + 1) × 50`，**50 分 = 中性**。

| 100 分制区间 | 窗口评级 | 操作参考 | 建议仓位 |
|--------------|----------|----------|----------|
| 83.0 ~ 100.0 | 强多窗口（红） | 积极建仓 / 分批加仓 | 70–90% |
| 66.5 ~ 83.0 | 偏多窗口（橙） | 分批建仓，逢回调吸纳 | 40–60% |
| 33.5 ~ 66.5 | 中性窗口（蓝） | 观望或小仓试错 | 0–20% |
| 17.0 ~ 33.5 | 偏空窗口（绿） | 降低敞口 / 避险为主 | 0–20%（或对冲） |
| 0.0 ~ 17.0 | 强空窗口（深绿） | 清仓 / 严格避险 | 0% |

### 2.4 计算流程（公式）

```
参数映射分：score_i = fn_i(参数值_i)        （经验分段线性函数，-1 ~ +1，阈值处为校准锚点）
综合分：     comp    = Σ(score_i × w_i)     （全局权重加权，w 和 = 1.00）
对外展示：   score100 = (comp + 1) × 50      （0 ~ 100 分制，50 为中性）
窗口评级：   bandOf(comp) → 五档             （阈值 ±0.33 / ±0.66）
趋势层：     trendAssessment(nodes, params, comp)  （独立计算，只读确认，不计入 comp）
```

> **映射口径（v0.6.4 起）**：13 项映射由早期「阶梯函数」改为**保锚点分段线性** `ramp(points)`——阈值处的经验取值原样保留（校准含义不变），阈值之间线性插值。这样 DXY 103.49→103.84、VIX 25.46→24.56 等日间小幅变动会反映到综合分，避免「参数天天变、指数月月不变」。前后端以 `server/lib.js` 为单源，`index.html` 内联 JS 同步。

## 六、每日自动更新

- **北京时间 08:30**（UTC 00:30）执行：抓取最新行情 → 计算综合分/档位 → 写入当日归档 → 更新 `index.json` / `snapshot.json` / `gold_kline.json` → 重新发布云端
- 数据源全部经 WebFetch（或腾讯自选股连接器）获取，不经 Python 直连外部 API；任一来源失败沿用上次有效值并标记 `stale`，不写空数据
- **抓数全失败不写盘**：杜绝常驻服务用 DB 旧快照回放覆盖当日新数据（v0.6.4 修复）
- 本机浏览器记录（localStorage）仅存本机；服务端归档跨设备可追溯

## 七、独立后端 API（可选 · Node.js + Express + SQLite）

### 7.1 启动

```bash
cd gold-window-app/server
npm install
node server.js                     # http://127.0.0.1:8888（默认监听 0.0.0.0）

```

### 7.2 API 一览

| 接口 | 说明 |
|------|------|
| `GET /api/health` | 健康检查 + 数据库计数 |
| `GET /api/snapshot` | 最新市场快照（补全 comp/score100/band/trend，freshness 以磁盘为真值） |
| `GET /api/history?from=&to=&limit=` | 逐日归档列表（升序） |
| `GET /api/history/:date` | 单日归档 |
| `GET /api/gold-kline` | COMEX 金价日线（每次请求与磁盘 JSON 同步，滞留旧窗口已修复） |
| `GET /api/gold-cycles` | 2000/2008 泡沫周期月均价与拐点（静态 JSON，不入库） |
| `GET /api/bands` | 五档阈值 + 权重表 |

### 7.3 特性

- **JSON 为真值源、SQLite 为查询副本**：每次 API 读取前幂等对齐，消除 00:30~08:30 的滞后窗口
- **启动自动回填 + 迁移**：先 `backfill.js` 补金价对齐与旧档 comp，再 migrate 到 SQLite（顺序不可反）
- **金价曲线取最新窗口**：按日期降序取最近 N 条再反转，避免停留在最旧区间
- **前端优雅降级**：API 优先、静态 JSON 兜底，本地与云端两套环境互不影响
