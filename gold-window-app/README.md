# 贵金属投资窗口预期评估器（PM-Evaluator）

> 面向黄金 / 白银等贵金属金融衍生品的**投资窗口预期评估**交互式 Web 应用。
> 基于「主权国家 / 美元指数 / 美债收益率」三大支柱框架，对 13 项黄金定价因子按典型经验赋权，
> 输出 **0~100 分制综合分** 与 **五档窗口评级**，为入场时机提供有指向性的参考建议。

- **版本**：v0.4（2026-08-26）
- **形态**：单文件 HTML + ECharts（CDN）+ 内联 JS/CSS，零依赖构建，可直接静态托管
- **数据**：每日自动刷新，按日归档，跨设备可追溯

## 二、评估体系

### 2.1 三支柱框架

| 支柱 | 权重 | 覆盖维度 |
|------|------|----------|
| 支柱一 · 实际利率与美债收益率 | 38% | TIPS 实际利率、名义收益率、政策利率、曲线斜率 |
| 支柱二 · 美元指数与政策分化 | 27% | DXY、贸易加权美元、美欧政策利率分化 |
| 支柱三 · 主权央行与避险需求 | 35% | 央行购金、地缘风险、美元信用风险、VIX、GLD ETF 资金流 |

### 2.2 13 项评估参数与权重（全局权重和 = 1.00）

| 参数 | 所属支柱 | 权重 | 方向（对金价） |
|------|----------|------|----------------|
| 10Y TIPS 实际利率 | 一 | 17% | 实际利率↑ → 金价↓（负相关） |
| 10Y 名义国债收益率 | 一 | 8% | 收益率↑ → 金价↓ |
| 2Y 国债收益率 | 一 | 5% | 政策预期定价 |
| 联邦基金利率 | 一 | 6% | 利率中枢高 → 金价承压 |
| 收益率曲线斜率 2s10s | 一 | 2% | 倒挂 → 衰退避险 → 利多 |
| 美元指数 DXY | 二 | 15% | 美元越强 → 金价越弱 |
| 美元贸易加权指数 | 二 | 7% | 广义美元强弱 |
| 美欧政策利率分化 | 二 | 5% | 美溢价宽 → 美元强 → 利空 |
| 全球央行季净购金 | 三 | 9% | >300t 强多（结构性底） |
| 地缘风险指数 GPR | 三 | 7% | 避险需求 |
| 美元信用风险指数 | 三 | 6% | 财政/赤字风险 → 利多 |
| 避险情绪 VIX | 三 | 5% | 恐慌升温 → 避险利多 |
| GLD ETF 月度流量 | 三 | 8% | 净流入 → 机构支撑利多 |

### 2.3 100 分制与五档窗口

- 内部评分口径为 **-1 ~ +1**（每个参数经经验映射函数得到利多/利空强度），对外展示统一换算为 **0~100 分制**：`分 = (内部分 + 1) × 50`，**50 分 = 中性**。

| 100 分制区间 | 窗口评级 | 操作参考 | 建议仓位 |
|--------------|----------|----------|----------|
| 83.0 ~ 100.0 | 强多窗口（红） | 积极建仓 / 分批加仓 | 70–90% |
| 66.5 ~ 83.0 | 偏多窗口（橙） | 分批建仓，逢回调吸纳 | 40–60% |
| 33.5 ~ 66.5 | 中性窗口（蓝） | 观望或小仓试错 | 0–20% |
| 17.0 ~ 33.5 | 偏空窗口（绿） | 降低敞口 / 避险为主 | 0–20%（或对冲） |
| 0.0 ~ 17.0 | 强空窗口（深绿） | 清仓 / 严格避险 | 0% |

### 2.4 计算流程（公式）

```
参数映射分：score_i = fn_i(参数值_i)        （经验分段函数，-1 ~ +1）
综合分：     comp    = Σ(score_i × w_i) / Σw_i   （全局权重加权，w 和 = 1.00）
对外展示：   score100 = (comp + 1) × 50           （0 ~ 100 分制，50 为中性）
窗口评级：   bandOf(comp) → 五档                   （阈值 ±0.33 / ±0.66）
```

示例参数：10Y TIPS 实际利率（负相关）——实际利率 ≥2.5% 映射 -1（极大利空），≤-0.5% 映射 +1（极强利多）。

## 六、每日自动更新

- 已配置每日自动任务：**北京时间 08:30**（UTC 00:30）执行
- 流程：抓取最新行情（腾讯自选股 + 美财政部 + FRED + MarketWatch）→ 计算综合分/档位 →
  写入当日归档 `history/YYYY-MM-DD.json` → 更新 `index.json` 与 `snapshot.json` → 重新发布云端
- 本机浏览器记录（localStorage）仅存于本机；服务端归档跨设备可追溯

## 七、独立后端 API（阶段 3 · Node.js + Express + SQLite）

在静态版之上提供**可读写的独立后端**：数据入库、每日定时抓数写库、前端 API 优先读取。

### 7.1 目录

```
server/
├── server.js          # 入口：Express 静态托管 + /api/* + 每日 08:30(北京) 定时任务
├── db.js              # node:sqlite 数据层（Node 22 内置，零编译依赖）
├── lib.js             # 评分映射/权重/计算（与前端 index.html 口径完全一致）
├── fetcher.js         # 在线抓数（美财政部 + FRED + MarketWatch，尽力而为）
├── package.json
└── start-server.bat   # Windows 一键启动脚本
```

### 7.2 启动

```bash
cd gold-window-app/server
npm install        # 首次需要（仅安装 express）
node server.js     # 默认 http://127.0.0.1:8888
# 或指定端口：PORT=8890 node server.js
# Windows 双击 start-server.bat [端口]
```

### 7.3 API 一览

| 接口 | 说明 |
|------|------|
| `GET /api/health` | 健康检查 + 数据库计数 |
| `GET /api/snapshot` | 最新市场快照（自动补全 comp/score100/band） |
| `GET /api/history?from=&to=&limit=` | 逐日归档列表（升序） |
| `GET /api/history/:date` | 单日归档 |
| `GET /api/gold-kline` | COMEX 金价日线 |
| `GET /api/bands` | 五档阈值 + 权重表 |

### 7.4 特性

- **启动自动迁移**：把 `data/` 现有 JSON（快照/57+ 归档/金价 K 线）导入 SQLite（`server/pm.db`），幂等可重复
- **每日定时任务**：北京时间 08:30 尝试在线抓数 → 计算综合分 → 写 SQLite + 同步回 `data/` JSON（云端静态版保持同步）；抓取失败自动沿用最近快照并标记 `stale`
- **前端优雅降级**：`index.html` 数据读取层为「API 优先、静态 JSON 兜底」——本地连后端走 API，云端纯静态部署自动回退 JSON，两套环境互不影响
